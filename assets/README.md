# Logo assets

SVG and 512 × 512 transparent PNG artwork from the
[libtmux logo kit](https://github.com/libtmux/assets), revision
`ef6c550b8d1120fe6873e610ddbe550f95016a46` (`assets/haskell/library`, primary
`#5E5086`).

Library marks use the cog, workspace marks the tiled tmuxp base, and MCP
marks the Model Context Protocol symbol. Language colors follow
[GitHub Linguist][linguist]. The source libtmux and tmuxp artwork belongs to
the project owner. The MCP symbol comes from the [upstream logo][mcp-logo].

Package-specific artwork sits beside its README where the package format
supports it. `.github/social-preview.png` is the cog sharing card, ready to
upload under the repository's **Settings → Social preview**.

The sharing card comes from `assets/haskell/library/opengraph-light.png`
at kit revision `a6377dd4fbfe0d5e59271ceefb21cb503646dbc0`.
